# Existing alternatives

Primary pages checked on 12 November 2026. These are publisher claims, not
independent accuracy, privacy or device benchmarks.

| Product | Relevant behavior | Difference from Selia Speak's brief |
| --- | --- | --- |
| [Phravia](https://phravia.com/) | Existing keyboard, floating microphone, cleanup, Android and Windows, local or cloud options, 75+ languages. Formerly named VoiceFlow. | Closest existing product. Local transcription is described as available where supported; it is not exclusively local. |
| [Wispr Flow](https://wisprflow.ai/android) | Floating microphone, existing keyboard, real-time self-corrections, 100+ languages. | Official Android FAQ requires Android 13+ and an internet connection. |
| [FUTO Voice Input](https://github.com/futo-org/voice-input) | Local Android dictation, Whisper/Parakeet/asr4all models, supported third-party keyboards. | Keyboard/API integration differs; its README lists Gboard and Samsung Keyboard as incompatible. Development focus has shifted toward FUTO Keyboard. |
| [Sayboard](https://github.com/ElishaAz/Sayboard) | Local Vosk voice keyboard with built-in model download and model import. | Uses a voice IME instead of the requested floating control alongside any existing keyboard. |

The opportunity is the requested combination: Android 9+, local-only processing,
an existing keyboard, clear model/language selection, and honest download size,
capability and benchmark information. These pages do not establish that this
combination is unique. No competitor source, artwork or product screenshots were
copied into Selia Speak.
